Randomness source

This phrase is generated using your browser's built-in crypto.getRandomValues() — a cryptographically secure pseudorandom number generator (CSPRNG) provided by your operating system. It's the same class of random number generator that underlies HTTPS/TLS security across the web, and is a well-audited, standard source suitable for generating cryptocurrency keys.

Optional: add physical dice

What this is for: the CSPRNG above is already cryptographically secure on its own — dice are entirely optional. Their purpose is independence: if you'd rather not have to trust this specific device's random number generator alone (for example, on a machine you're not sure is clean, or if you just want a second, physically-verifiable source of randomness you control yourself), roll physical dice and enter the results below. They get combined with the CSPRNG output by hashing both together, so the result is never weaker than the CSPRNG alone — only ever stronger. Leave this blank if you're happy trusting the CSPRNG by itself.

Optional: passphrase

What this is for: an optional extra secret — sometimes called the "25th word" — added on top of your 12/24-word phrase. It creates a separate hidden wallet: the exact same words combined with a different passphrase (including a blank one) produce a completely different, unrelated wallet address. Anyone who finds your written-down words alone cannot access a passphrase-protected wallet without also knowing the passphrase.

! The passphrase is case-sensitive and must be entered exactly the same way every single time — including spaces, punctuation, and special characters. There is no way for this tool (or any wallet) to tell you if you've mistyped it: get it even slightly wrong during recovery and you will silently land on a different, wrong wallet with no error message. If you set a passphrase and later forget or mistype it, any funds in that wallet are permanently unreachable, even with your 12/24 words intact. Leave this blank if you don't specifically want this feature.

Derive a Bitcoin (BTC) address

Native SegWit uses path m/84'/0'/0'/0/{account index} (bech32, bc1...) — the current default for Electrum, Trezor, Ledger and most modern wallets. Legacy uses m/44'/0'/0'/0/{account index} (1...). Uses the passphrase entered above, if any.

Test a phrase & check its addresses

Paste a BIP-39 phrase back in (yours, or one from another wallet) to confirm its checksum is valid, and derive its Ethereum/EVM and Bitcoin addresses so you can cross-check them against what your wallet app shows. This is a good way to confirm you wrote your words down correctly before you rely on them — generate a phrase, note the addresses it produces, then paste the same words in here and confirm you get the same addresses back.

What this tool does

This page implements BIP-39 (the standard 2048-word mnemonic scheme) directly in JavaScript, using your browser's built-in crypto.getRandomValues and crypto.subtle (Web Crypto) for all randomness, hashing and PBKDF2 — plus from-scratch, independently-verified implementations of secp256k1, Keccak-256, RIPEMD-160, Base58Check and Bech32 to derive Ethereum/EVM and Bitcoin addresses (browsers don't have any of these built in). No external libraries, no CDNs, no network requests of any kind. The BIP-39 word list (2048 words) is the exact, verified standard list, embedded directly in this file.

Security notes

  • Run this from a local file (or an air-gapped machine) for real use — do not enter a real phrase into a copy of this page loaded from a server you don't control. If you're using a copy hosted on GitHub Pages (or similar) that you or someone you trust controls, that's safer than an unknown third-party site, but downloading the file and opening it locally (or disconnecting from the internet after the page loads) remains the most cautious option for real funds.
  • This tool cannot verify itself against tampering. If you didn't get this file from a source you trust, treat its output with suspicion and cross-check with another independent implementation before trusting it with real funds.
  • There is deliberately no clipboard-copy function for seed words or private keys anywhere in this tool — only the derived public address can be copied. This is a one-way door: don't work around it by manually selecting and copying the words yourself if you're trying to keep them off the clipboard.
  • Words are hidden by default and only shown after you click "Reveal" — make sure your screen isn't visible to anyone else, and isn't being recorded or screen-shared, before revealing.
  • Every phrase generated here is checked against its own checksum before being shown to you — but this is not a substitute for testing recovery in a real wallet before relying on a backup.
  • The Ethereum address feature derives at the standard m/44'/60'/0'/0/{account index} path used by MetaMask and most Ethereum/EVM tooling. The Bitcoin address feature derives Native SegWit at m/84'/0'/0'/0/{account index} (today's default in Electrum, Trezor, Ledger and most wallets) or Legacy at m/44'/0'/0'/0/{account index}. Both were verified against official BIP test vectors (Ethereum: the well-known Hardhat/Foundry test mnemonic; Bitcoin: the official BIP-84 test vector and an independent BIP-32 test vector) before being included here.
